Add extended custom splitter class named ExtendedGroupShuffleSplit to the custom_splitter.py:
At its core, it provides randomized train/test splits based on groups like group shuffle split from scikit learn but extends its functionality by sampling the test set with or without replacement, hence, not allowing repetitions of test set group combinations until all possibilities are exhausted.
Sampling without replacement is implemented by two different mechanisms depending on the amount of test set group combinations. For low numbers, an exhaustive approach is used. For a high number of potential test set groups combination, a sample and reject approach is used.
